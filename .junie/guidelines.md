# Project Guidelines
    
This project uses bun as package manager and build tool

## Git Guidelines
- Make commits after each task
- Make commits with meaningful messages
- Use `Junie AI` as the comitter name
- You may only execute `git -c user.name="Junie AI" commit`, `git status` and `git add`, all other commands are forbidden
- Never run the `build:exe` script, this is reserved for releases

As an option you can ask Junie to create these guidelines for you.
